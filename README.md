# Jakorchi

Free food guide for travelers in Japan, Korea and China: restaurants on a map, halal / vegan filters, reviews with prices in local money, 9 languages.

- **Live:** https://jakorchinavigation.jakorchi.workers.dev (every push to `main` publishes by itself, Cloudflare Workers Builds)
- **Repository:** public on purpose; it holds no secrets and must never hold any.
- **Front end:** being rebuilt screen by screen; the old version is git tag `old-app-final`.
- **Folders:** `public/` website · `tools/` helper scripts · `database/` Supabase setup · `docs/` short notes
- **Rules, release steps, safety:** see `CLAUDE.md` and `docs/`.
- Map and places © OpenStreetMap contributors (ODbL).
