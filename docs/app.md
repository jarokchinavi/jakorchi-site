## Map screen + place card (built 2026-11-16, owner picked every design)
- Files: `index.html` section `#mapscr` + sheets `#menuSheet #saveSheet #navSheet #revSheet #repSheet #filtSheet` · `css/map.css` (pins, search bar, chips, sheets, menu, zoom ring) · `css/card.css` (place card, swipe row, tabs, sheets) · `js/router.js` (screens, `data-go`) · `js/sheet.js` (slide-up sheets, one history step) · `js/maplib.js` (MapLibre GL 4.7.1 from unpkg with SRI, OpenFreeMap styles, labels follow `jk_maplet`) · `js/map.js` · `js/places.js` (loads `places/<x>_<y>.json` squares only at classic zoom ≥ 13, max 6 (9 big screen) nearest the middle, 1200 rows per portion) · `js/pins.js` + `js/pinui.js` (pins) · `js/ratings.js` (reads `place_ratings`) · `js/lists.js` + `js/save.js` + `js/menu.js` (Favorites, Want to go, Bakery, Coffee + own lists, menu sheet) · `js/search.js` · `js/food.js` · `js/filters.js` · `js/peek.js` (card) · `js/reviews.js` · `js/report.js` · `js/navigate.js` · `js/sb.js` (Supabase calls; device id `jk_dev`).
- Zoom: classic zoom = MapLibre zoom + 1 (the old thresholds still apply). Below 13 no pins except saved places · 13–14 stacks (cell 120/96 px, tap = zoom +2) · ≥ 15 rating-pill pins, best first, caps 18/30/48/70/100 · redraw ≤ every 200 ms · saved places always shown (never stacked). Colours: gold pill = saved, red = favorite.
- Place card: rating, pills (price range, food type, Halal / Vegan tags), swipe row (Navigate, Save to a list, Write a review, Food type, Share, Report wrong info), tabs Details (Address copy in one tap, Phone, Opening hours, Website) / Reviews / Menu photos. Navigate sheet: only the map apps that fit the phone + Copy address / Copy coordinates (only there). Report sheet: Halal / Vegan / food type / closed, one answer per phone, enforced by the database.
- Food type (`js/food.js`): typing field with typo help (old rules: `fold` + `near`, fewer than 4 hits → typo pass) in any language (names from `lang/foods.json`). Visitor reports only accept the fixed list of 38 kinds (`food:<slug>`, database rule). Used in the report sheet, the Filters food box and the search bar (food-type suggestions on top; tap = filter food). Halal / Vegan buttons were removed from the card swipe row (owner, 2026-11-16); the Diet filters and the report rows stay.
